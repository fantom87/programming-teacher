Issue 12

The Paper Lantern Review

A quarterly zine about small lights: porch bulbs, bike reflectors, the glow of a toaster working hard. This issue we interviewed a lighthouse keeper who has never once been asked about the light.

"People ask about storms. They ask about loneliness. Nobody asks what four thousand watts feels like at 2am. It feels like company."
